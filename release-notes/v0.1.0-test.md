# 首次测试版：官方 OAuth 图片理解

独立识图插件，支持官方 Sign in with ChatGPT 授权、账号模型读取、图片描述、截图理解与 OCR。提供独立代理配置、凭据加密存储和用户/群权限控制。

这是保留的初始测试快照，存在后续版本已修复的流式响应兼容问题，建议使用 v0.1.3。

升级时停用插件，用附件 ZIP 内同名目录的文件覆盖原插件目录后重载。保留 data/plugin_data/astrbot_plugin_chatgpt_vision；兼容已有授权，无需为升级重新登录。

下载下方插件 ZIP 及对应 .sha256 文件。附件保持此前交付的原始字节；GitHub 自动生成的 Source code 包与插件安装包用途不同。

本插件只提供图片理解，不提供 OAuth 图像生成，不采集账号密码或浏览器 Cookie。测试不等于所有账号权限、代理或第三方 QQ 适配器均已通过联调。
