# 可选用量统计与插件图标

OAuth 识图新增可选数字用量上报，支持同一 Release 附带的独立“模型用量统计”插件。仅记录接口返回的 Token、模型和状态，不记录图片、问题、答案或令牌；缺失用量保持未知。订阅调用不按 API 单价估算费用，也不推算剩余额度。

仓库根目录加入用户提供的原始 logo.png。插件名称与原仓库地址保持，metadata.yaml 版本更新为 v0.1.5。已有权限、模型、代理与授权继续使用，无需重新登录。

升级识图插件可使用 AstrBot 原仓库更新，或安装 astrbot_plugin_chatgpt_vision-v0.1.5-test.zip 后重载；保留 plugin_data。需要统计时，另从文件安装 astrbot_plugin_token_usage-v0.1.0-test.zip，重载后发送 `/token`，默认仅管理员可查。两个 ZIP 分别对应两个插件，请按名称安装。

附件包含两个安装 ZIP 和各自的 SHA-256 校验文件。旧版本附件保持原样。GitHub Windows/Linux CI 分别执行识图与发布流程回归、独立统计插件 43 项离线测试及安装包清单校验；测试使用模拟数据，不调用真实账号。真实 QQ、服务器及账户权限的端到端效果仍需现场验证。
