# 群聊默认全员与独立授权

选择目标群后，默认全体成员可用。新增“群内单独授权”复选框，开启才显示“群内可用成员”选择器；此时仅名单成员和机器人管理员可用。私聊保留独立名单，两份名单互不授权；未选中的群一律不可用。

精简所有插件设置描述。兼容原有群号与私聊名单，引用识图、代理和OAuth授权保持。无需重新登录或安装依赖。

目标群与用户选择器采用官方umo/sender_id接口。AstrBot 4.29.3 WebUI没有这两个选择器，会退回手动填写名单；条件显示可用。点选需支持新选择器的WebUI。

升级：停用插件，覆盖ZIP内同名目录文件后重载，检查目标群和新开关并保存。不要清理plugin_data。若需保持逐人限制，请开启群内单独授权并选择成员。

验证：增加群聊全员、名单隔离、空名单拒绝、跨实例群匹配、权限先于图片读取等测试；完整回归由Windows/Linux CI执行。未在用户服务器执行真实QQ端到端测试。
