# 模型用量统计

独立 AstrBot 插件，记录模型返回的 Token 用量，支持 QQ 统计卡片与文本查询。统计从安装启用后开始，不自动导入历史，也不查询账户余额。

## 安装与查询

在 AstrBot 插件页从文件安装本插件 ZIP，重载后开始记录。Pillow 已是 AstrBot 的依赖；无安装脚本、外部渲染服务或字体下载。

默认仅机器人管理员可查询：

```text
/token
/token 近7天
/token 累计
/token 当前会话
/token 今日 全部
/token 累计 模型 实际模型名称
/token 今日 文本
```

默认只查当前会话来源（群或私聊）；“全部”仅管理员可查，包含未归属到会话的模型调用。“当前会话”使用 AstrBot 会话ID，重置会话后区分旧会话。未取得会话ID时不回退为查询所有会话。

允许成员查询时，将“谁能查询”改为“成员可查当前会话”。群成员看到的是本群来源的合计，不是个人账单；不能查看其他群或全局统计。缺少中文字体时返回文本，也可追加“文本”。

## 价格

“模型单价”中添加实际模型名称及每百万 Token 单价。提供商ID可选；有精确ID的条目优先。支持 CNY、USD、EUR，不自动换汇。价格会在记录写入时保存快照，修改价格不会重算旧记录。

输入 Token 包含缓存；费用只计算普通输入、缓存读取、缓存写入及输出各自对应的部分，避免重复计算。接口单列缓存写入且用量大于零时，必须填写缓存写入单价，否则费用显示未知。价格留空表示未知；只有明确填入0才代表该项单价为0。

缓存字段缺失显示未知，不能从缺失数据推断零命中。缓存比例按已报告缓存字段的输入Token加权，显示覆盖次数；费用只显示已计价部分，不是供应商账单。工具费、图片按张计费、音频、批处理、阶梯价及上下文长度分档等不在本版估算范围；须自行设置适用的单价，不应据此核对所有费用。

## OAuth 识图

同时安装 ChatGPT OAuth 识图 v0.1.5 或更新版，即可接收其QQ识图调用的数字用量。旧版需升级；不重新登录。该插件的独立HTTP请求不能通过普通Provider观察自动捕获。

OAuth记录始终标为订阅调用，不套用API单价、不推算余额、剩余百分比或重置时间。管理脚本中的登录、模型目录、自检不属于QQ会话，不计入这条上报链路。

## 统计范围与隐私

- 通过可恢复的实例方法包装观察 AstrBot 聊天提供商的 `text_chat` / `text_chat_stream` 返回值，不改HTTP库、认证或请求参数；卸载时恢复原方法。
- 普通回复、工具循环中的提供商调用、直接使用这些提供商接口的第三方插件均可记录。流式取最后一份汇总用量，不逐块累加；同一提供商调用内部嵌套的接口不重复统计。私自直连HTTP、外部执行器和不经过这两个方法的模型调用不自动覆盖；代理内部的重试、路由和隐藏请求无法逐次核对。
- 对常见 OpenAI Chat/Responses、DeepSeek缓存字段、Anthropic分列缓存、Gemini用量及AstrBot标准用量做保守解析。未知格式显示未知；AstrBot标准对象默认的0缓存不能证明接口报告过缓存。
- 数据保存在本插件专属 `usage.sqlite3`。只保存时间、匿名化会话键、提供商/模型名称、数字用量、状态和价格快照。不写入聊天正文、图片、模型答案、请求参数、密钥或OAuth令牌。
- 记录失败或队列满会标记统计不完整，不能作为精确账单。正常停用会尝试排空队列；突然断电、强制结束或尚未完成的调用可能未落盘。
- 默认保留90天、至多10万条；达到上限会分批删除最旧记录。因此“累计”是当前保留数据累计，不是账号终身用量。查询不额外调用模型。

## 接入接口

OAuth插件通过 `context.get_registered_star('astrbot_plugin_token_usage')` 获取已启用插件实例，再调用 `ingest_external(event, request_id=唯一ID, model=模型名, usage=仅数字usage, status=状态)`。该接口将来源固定为ChatGPT订阅，不接受计费类型覆盖。相同request_id只写入一次。

## 测试与许可证

在本目录使用已有Pillow运行 `python -m unittest discover -s tests -v`。测试只用模拟提供商、合成数字和临时数据库，无真实账户或模型请求。真实QQ与用户服务器联调仍需反馈。
